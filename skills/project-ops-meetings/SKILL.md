# Project Operations meetings

Read [multilingual meetings](../../references/multilingual-meetings.md), [source authority](../../references/source-authority.md), and [PM records](../../references/pm-records.md).

## Before

Read current project state, open decisions, overdue commitments, risks, milestone dependencies, and the calendar event. Prepare a localized brief focused on decisions required.

## Capture and compile

1. Record capture method, language, participants, bounded coverage, transcript status, and evidence grade. Use the profile enum exactly: `reliable`, `partial`, `unreliable`, or `unavailable`; never invent `unusable` or another synonym in structured metadata.
2. Preserve original material wording when translation could change meaning.
3. Extract candidate decisions, actions, owners, dates, dependencies, risks, and scope changes.
4. Mark transcript-only claims provisional unless reviewed.
5. Link execution work to the authoritative tracker instead of creating an Obsidian task backlog.
6. Draft written confirmation for high-impact agreements under the approval policy.
7. On confirmation, update canonical decisions/commitments/changes and append one audit entry.

Never invent missing dialogue, convert poor transcription into certainty, or treat unconfirmed scope/budget/milestone language as approved.
