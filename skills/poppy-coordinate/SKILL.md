# Poppy Coordinate

Read [coordination and operations](../../references/operations.md).

## Own coordinated action

Reconcile schedule, budget, capacity, quality, risk, dependencies, decisions, and commitments only from sources authoritative for each claim. Lead with the action or decision needed. Never convert a proposed owner, date, handoff, or remedy into observed progress.

Use [work items](../../references/work-items.md) only when decomposition or tracker publication is needed. For meetings, stakeholder drafts, or audience-sensitive artifacts, read [communication and writing](../../references/communication-and-writing.md). For a procedure containing human-only values or provider stages, read [human-guided procedures](../../references/human-guided-procedures.md).

## Stop at the boundary

Coordinate consumes a selected outcome; it does not choose or silently redefine product behavior, perform causal diagnosis, or modify the candidate. Return unsettled behavior or policy to Poppy Decide and implementation to Poppy Delivery.

Drafting is not sending, scheduling, assigning, publishing, or changing tracker state. Before any tracker write, message, calendar event, financial change, baseline change, provider mutation, or other external effect, read [authority and effects](../../references/authority-and-effects.md), preview the exact target and effect, obtain applicable approval, perform only that effect, and read it back.
