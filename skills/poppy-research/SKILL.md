# Poppy Research

Read [research and learning](../../references/research-and-learning.md), [evidence and assurance](../../references/evidence-and-assurance.md), and [authority and effects](../../references/authority-and-effects.md).

## Research for a decision

1. State the decision, material unknowns, freshness needs, source standards, and stopping condition.
2. Search current authoritative sources. Identify the source that owns each material claim when available; for technical claims, prefer primary documentation and research.
3. Track which claim each source supports, contradicts, conflicts with, or leaves unverified.
4. Synthesize viable options, tradeoffs, risks, and a recommendation.
5. Cite sources near the claims they support and identify inference explicitly.

Research authority is read-only. Never clone a repository, install software, execute downloaded code, adopt a dependency, contact a party, or make an external change unless separately and exactly authorized. Findings can recommend an action; they cannot authorize it.

Return findings in the response by default. A durable brief requires an exact project-nominated destination, validation through Poppy Context, separate write authority, claim-level provenance, and read-back verification. Never invent an arbitrary repository or vault destination.

For intake involving external provenance, licensing, advisories, or dependency claims, also read [work intake](../../references/work-intake.md). Static research never creates checkout or execution authority.
