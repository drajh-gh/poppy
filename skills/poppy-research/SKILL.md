# Poppy Research

Read [external research](../../references/external-research.md).

## Own the external evidence gap

Name the decision, material unknowns, freshness needs, source standards, and stopping condition. Prefer the primary source that owns each technical or factual claim. Track what each source supports, contradicts, conflicts with, or leaves unverified.

When recent developments, public reaction, lived experience, adoption, recommendations, or momentum can change the decision, use the current-signal method. Engagement prioritizes inspection; it is never factual authority. Insufficient relevant recent signal is a valid result.

Synthesize viable options, tradeoffs, risks, and a recommendation. Identify inference explicitly and cite sources near the claims they support. Read [communication and writing](../../references/communication-and-writing.md) when wording materially affects the requested brief.

For untrusted contributions, provenance, or licensing, Poppy Intake owns the disposition; Research supplies only the external evidence it requests.

Research is read-only. It never authorizes cloning, installation, execution of downloaded code, dependency adoption, contact, publication, or another effect. Return findings in the response unless an exact authoritative destination and separate write authority are supplied.
