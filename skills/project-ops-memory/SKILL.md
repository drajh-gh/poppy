# Project Operations memory

Read the vault `AGENTS.md`, project index, current page, and source map. Read [source authority](../../references/source-authority.md), [connector adapters](../../references/connector-adapters.md), and [PM records](../../references/pm-records.md).

## Ingest or refresh

1. Identify the authority, stable source ID, bounded coverage, language, sensitivity, evidence grade, and known gaps.
2. Retrieve the bounded corpus completely and reconcile counts or revisions.
3. Add an immutable sanitized receipt; never rewrite raw history.
4. Search canonical pages before creating a new one.
5. Compile verified facts, interpretations, decisions, contradictions, and open questions.
6. Update `valid_as_of` and `review_after` only after rereading authority.
7. Update navigation only when it changed, append one log entry, and lint.

## Query

Read the smallest compiled working set. Follow receipts or live sources for current/high-impact claims. State when evidence is stale, conflicting, provisional, or missing. File an answer back only when it adds durable knowledge.

Never mirror entire Drive folders or channels by default, store secrets or raw production rows, treat Slack as approved scope, or turn the refresh queue into a task backlog.
