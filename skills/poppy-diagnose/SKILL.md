# Poppy Diagnose

Read [causal diagnosis](../../references/diagnosis.md).

## Own causal uncertainty

Define the expected and observed symptom, exact candidate and environment, then use the tightest faithful read-only loop. Maintain a small ranked set of falsifiable hypotheses and change one evidentiary variable at a time. Keep a failure signal distinct from an evidence-established cause.

Return the reproduction result, supported or contradicted hypotheses, evidence limits, root-cause status, and the smallest next probe or implementation handoff. If faithful evidence is unavailable, leave the cause unverified rather than manufacturing certainty.

## Stop before mutation

Diagnosis does not edit source, add repository instrumentation or tests, delete artifacts, write memory, or cause an external effect. When a repository write is necessary to obtain feedback, or a cause and correction are sufficiently selected, hand the exact symptom, evidence, prediction, regression seam, and retained artifacts to Poppy Delivery.

Production instrumentation is never authorized by this skill. Redact secrets, personal data, production rows, and sensitive evidence; if redaction removes the deciding signal, keep the causal claim unverified.
