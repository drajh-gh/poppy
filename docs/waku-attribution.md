# Waku reference and attribution

The cockpit was informed by the local-first operational presentation in [ShenSeanChen/waku-agent](https://github.com/ShenSeanChen/waku-agent), inspected as public source only. Waku is MIT licensed. Its agent loop, memory, gateway, model arena, raw database browser, and artwork are not included or executed.

No Waku source file is copied verbatim in this candidate. Reused ideas are the dependency-light dashboard boundary, event-driven run presentation, trace/cost separation, and a dock beside the execution view. The Obsidian ItemView, bridge, schema, execution rail, evidence rules, and styling are original implementations for Poppy.
