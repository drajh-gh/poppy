# Durable learning

## Learn from evidenced outcomes

Review the completed outcome, not merely the process. A lesson is durable only when evidence shows that it is likely to change future decisions or execution. Do nothing for trivial, read-only, review-only, diagnosis-only, proposed, conflicted, or unverified material.

Capture the smallest reusable statement, its scope, decisive evidence, and any counterexample or expiry condition. Do not turn task narration, preferences inferred from one exchange, or transient tracker state into memory.

Retry counts, provisional risks, self-review notes, course-correction observations, and assurance packets are working context. Repetition within one task does not establish a recurring durable lesson.

Poppy Scribe may identify a recurring friction candidate only when the same supported fingerprint appears across explicitly supplied summaries or explicitly selected configured records from at least three independent tasks. That threshold makes a review worthwhile; it does not prove a durable lesson or authorize any change. Learn still requires a completed evidenced outcome, representative examples, scope, a counterexample or expiry condition, and the destination-specific authority below.

Classify before choosing a destination:

- a project fact, rationale, or domain lesson belongs in nominated project memory when policy and authority permit;
- a recurring repository-level correction may justify a project-owned structural guard;
- a Poppy-wide behavior change requires a separate versioned Poppy candidate and matched behavioral evaluation.

## Prefer proportionate structural prevention

When the same supported correction recurs, consider whether a type, test, lint rule, script, metadata constraint, template, or runtime check would prevent it more reliably than another instruction. Choose the smallest mechanism proportionate to frequency, consequence, maintenance cost, and false-positive risk.

This is a proposal heuristic, not authority. Do not automatically create tooling, mutate policy, file tracker work, rewrite skills, or install a candidate. A structural guard still needs an exact owner, target, implementation scope, review, verification, and any effect-specific approval.

## Write only to an authorized memory surface

For project memory, confirm identity, exact destination, confinement, source authority, memory policy, and provenance through Poppy Context. Prefer an existing canonical page. Preserve frontmatter, links, freshness, aliases, translations, contradictions, human-owned surfaces, and immutable receipts. Keep tracker state in the tracker.

Preview the exact change, obtain required approval, write only that surface, and read it back. A lesson does not authorize its own capture.
