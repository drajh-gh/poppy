# Adopt the Project Operations PM branch

## Proposed decision

Add the Project Operations PM branch and onboarding profile while preserving external source authority, the tracker boundary, human-owned notes, immutable raw history, existing project-specific delivery rules, and approval gates.

## Consequences

- Obsidian gains PM control records and Bases.
- Project execution remains in the tracker and repository.
- Existing Delivery OS adapters remain project-specific until their own extraction gate is satisfied.
- Portfolio publication is limited to sanitized summaries.

Accept this decision only after reviewing the onboarding dry run and source-authority map.
